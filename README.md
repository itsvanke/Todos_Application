Advanced Todo Application

A feature-rich Todo Application built using HTML, CSS, Bootstrap, and Vanilla JavaScript.  
This project demonstrates CRUD operations, dynamic DOM manipulation, filtering logic, and LocalStorage persistence.



Features

- ✅ Add new tasks
- ✅ Edit existing tasks
- ✅ Delete tasks
- ✅ Mark tasks as completed
- ✅ Filter tasks (All / Active / Completed)
- ✅ Clear completed tasks
- ✅ Auto-save using LocalStorage
- ✅ Responsive UI using Bootstrap
- ✅ Enter key support for quick task addition


Tech Stack

- TML5
- CSS3
- Bootstrap 4
- Vanilla JavaScript (ES6)
- LocalStorage API

Concepts Implemented

- DOM Manipulation
- Event Handling
- State Management
- Array Methods (map, filter, find)
- CRUD Operations
- Browser LocalStorage
- Dynamic Rendering
- Conditional Rendering Logic
